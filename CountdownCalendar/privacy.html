Privacy Policy

プライバシーポリシー Privacy Policy

「あと何日？」（以下「本アプリ」）は、利用者のプライバシーを尊重し、必要最小限の情報のみを取り扱います。 本ポリシーでは、本アプリにおける情報の利用目的と取り扱い方法を説明します。 "Countdown" (the "App") respects user privacy and handles only the minimum information required. This policy explains what information is used and for what purpose.

最終更新日: 2026年9月5日

1. 取得・利用する情報 / Information We Access and Use

本アプリは、利用者が許可した場合に限り、端末のカレンダー情報へアクセスします。

The App accesses calendar information on the device only when permission is granted by the user.

アクセス対象には、予定のタイトル、日時、カレンダー識別情報、表示色などが含まれる場合があります。

This may include event titles, dates and times, calendar identifiers, and display colors.

2. 利用目的 / Purpose of Use

取得したカレンダー情報は、以下の目的のためにのみ利用します。

Calendar information is used only for the following purposes:

  • 次の予定までの残り日数・残り時間を表示するため / To show the time remaining until upcoming events
  • 予定一覧を表示するため / To display the event list
  • ピン留めした予定を優先表示するため / To prioritize pinned events
  • ウィジェットに予定情報を表示するため / To display event information in widgets

3. 情報の保存と処理 / Storage and Processing

本アプリが読み込んだ予定情報は、アプリ本体およびウィジェット表示に必要な範囲で、利用者の端末内に保存されます。

Event data read by the App is stored on the user's device only to the extent necessary for the app and widget display.

また、ウィジェット表示のために、アプリとウィジェット間で共有される端末内ストレージ領域を利用することがあります。

For widget updates, the App may use on-device shared storage between the app and widget extension.

4. Widget Pushとサーバーへ送信する情報 / Widget Push and Server Data

ウィジェットを定期的に更新するため、本アプリは以下の技術情報を開発者が管理するサーバーへ送信します。

To keep widgets up to date, the App sends the following technical information to a server managed by the developer:

  • Appleが発行するWidget Pushトークン / The Widget Push token issued by Apple
  • 本アプリが生成するランダムなインストール識別子 / A random installation identifier generated by the App
  • Push環境、設置されたウィジェット数、アプリバージョン / Push environment, configured widget count, and app version
  • APNsへの配信日時、結果、エラー情報 / APNs delivery time, result, and error information

これらは、有効なウィジェットの登録、Apple Push Notification service（APNs）を通じた更新要求の送信、配信状況の確認にのみ利用します。 カレンダーの予定タイトル、日時、メモ、カレンダー識別情報などの予定内容はサーバーへ送信しません。

This information is used only to register active widgets, send refresh requests through Apple Push Notification service (APNs), and check delivery status. Calendar content, including event titles, dates and times, notes, and calendar identifiers, is not sent to the server.

5. 外部サービス / External Services

Widget Pushの提供にはAppleのAPNsと、サーバー処理・キュー・データ保存のためにCloudflare Workers、Cloudflare QueuesおよびCloudflare D1を利用します。 これらの事業者は、サービス提供に必要な範囲で技術情報を処理する場合があります。

The App uses Apple's APNs for Widget Push and Cloudflare Workers, Cloudflare Queues, and Cloudflare D1 for server processing, queues, and data storage. These providers may process technical information as necessary to provide their services.

6. 保存期間と削除 / Retention and Deletion

Widget Pushの購読情報は、自動更新機能の提供と運用に必要な期間保存します。配信結果の履歴は原則として14日間保存した後、削除します。 無効になったPushトークンは配信対象から除外します。保存情報の削除に関するご依頼は、本ページ末尾の連絡先へお問い合わせください。

Widget Push subscription information is retained for as long as necessary to provide and operate automatic updates. Delivery-result history is generally deleted after 14 days. Invalid push tokens are excluded from future deliveries. To request deletion of stored information, contact us using the address at the end of this policy.

7. 第三者提供 / Third-Party Sharing

本アプリは、カレンダー情報およびWidget Push用の技術情報を、広告や行動追跡の目的で販売、共有、提供しません。 前項に記載したサービス提供者による必要な処理を除き、第三者へ提供しません。

The App does not sell, share, or disclose calendar information or Widget Push technical information for advertising or behavioral tracking. It is not disclosed to third parties except for the necessary processing by the service providers described above.

8. 解析ツール・広告SDK / Analytics and Advertising SDKs

本アプリは、利用者の行動追跡を目的とした広告SDKや、トラッキング目的の外部解析サービスを使用しません。

The App does not use advertising SDKs for behavioral tracking or external analytics services for tracking purposes.

9. 権限とWidget Pushの管理 / Permission and Widget Push Control

カレンダーへのアクセス権限は、iPhoneの設定画面からいつでも変更または取り消すことができます。 権限を許可しない場合、本アプリの一部機能は利用できません。

Calendar access can be changed or revoked at any time in iPhone Settings. If permission is not granted, some features of the App will not be available.

ウィジェットを削除すると、そのウィジェットに対する今後のWidget Push配信は停止されます。

Removing a widget stops future Widget Push deliveries for that widget.

10. 子どもの個人情報 / Children's Privacy

本アプリは、年齢を問わず利用できますが、意図的に子どもの個人情報を収集することを目的としていません。

The App may be used by people of any age, but it is not intended to intentionally collect children's personal information.

11. ポリシーの変更 / Changes to This Policy

本ポリシーは、法令やアプリ仕様の変更に応じて改定される場合があります。重要な変更がある場合は、アプリ配布ページまたは本ページ上で告知します。

This policy may be updated in response to legal requirements or changes in the App. Material changes will be announced on the app listing page or this page.
