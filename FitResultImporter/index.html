Fitness Game Result Importer

リザルト画面を、 ヘルスケアの ワークアウトへ。

Turn fitness game result screens into Apple Health workouts after review.

FitResultImporter は、リングフィットやFit Boxingなどのリザルト画面を撮影し、 運動時間と消費カロリーを読み取って、確認・修正後にAppleヘルスケアへ保存するiPhoneアプリです。 Capture or select a result screen, review the detected duration and active calories, then save it as a workout in Apple Health.

Capture / Select

いつものリザルト画面から Start with the result screen you already have.

ゲーム終了後の結果画面をカメラで撮るか、写真ライブラリから選択して取り込みます。 Use the camera or choose an existing screenshot/photo from your library.

On Device

解析は端末内で完結 Analysis runs on the device.

Vision OCRとオンデバイス解析で、運動時間と消費カロリーを読み取ります。 Vision OCR and local analysis extract workout duration and active calories.

HealthKit

確認してから保存 Review first, then save.

読み取り結果をそのまま保存せず、内容を確認・修正してからHealthKitへ登録します。 Detected values are shown for review and editing before they are written to HealthKit.

Features

運動記録を残しやすくするための機能 Features for cleaner workout logging.

運動時間と消費カロリーを読み取り Duration and calories

リザルト画面内の運動時間と消費カロリーを読み取り、ワークアウト登録に必要な値として整理します。 Extracts the core values needed to create a workout record.

手修正に対応 Manual correction

画像が見づらい場合や読み取りがずれた場合でも、保存前に日時、運動時間、消費カロリー、ゲーム名を直せます。 Edit the date, duration, calories, and game title before saving.

HealthKitへワークアウト保存 Workout save to HealthKit

単なるカロリー記録ではなく、フィットネスゲームのワークアウトとしてAppleヘルスケアへ保存します。 Saves entries as fitness gaming workouts, not just calorie-only records.

履歴と重複確認 History and duplicate checks

登録済みの取り込み履歴をアプリ内で確認できます。似た記録がある場合は、重複登録を避けやすくします。 Review imported workouts and reduce accidental duplicate saves.

Privacy

画像とヘルスケア情報の扱いを明確にしています Clear handling of images and Health data.

本アプリは、リザルト画像の読み取りとHealthKit保存のために必要な権限のみを使用します。 解析目的で画像やヘルスケア情報を開発者の外部サーバーへ送信しません。 The app uses only the permissions needed for result import and HealthKit saving, and does not send images or Health data to the developer's external servers for analysis.
